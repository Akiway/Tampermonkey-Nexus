# Tampermonkey-Nexus
UX improvements for Nexus Mods

## Installation (Tampermonkey - Raw button)
1. Install the Tampermonkey browser extension.
2. Open one of the script files in this repository:
   - `scripts/mod-page-ux.user.js`
   - `scripts/modrewards-ux.user.js`
3. Click the `Raw` button on GitHub.<img width="1739" height="189" alt="image" src="https://github.com/user-attachments/assets/eb8644be-6e8f-402a-b260-e0c323b100d2" />

4. Tampermonkey opens an install page. Click `Install`.<img width="625" height="335" alt="image" src="https://github.com/user-attachments/assets/0125d948-990c-40e1-97ea-b5ad4d56ed9b" />

5. Repeat for each script you want.

Direct raw links:
- https://github.com/Akiway/Tampermonkey-Nexus/raw/refs/heads/main/scripts/mod-page-ux.user.js
- https://github.com/Akiway/Tampermonkey-Nexus/raw/refs/heads/main/scripts/modrewards-ux.user.js


## Scripts
### modrewards
- Improve Mod rewards Wallet and Report pages with better tables, more detailed data and sortable columns.
- Improve Opt-in page with better tables, quantity selector (up to 100 mods per page) and sortable columns.

### mod-page
- Adds a second chart on mod Stats pages to show monthly unique-download totals and month-over-month evolution.
- New follower/endorser counters and lists in Logs tab
